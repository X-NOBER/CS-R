If you're using Wide screen, use the models inside Widescreen folder
if you're using normal screen, use the models inside Normalscreen folder


How to install:
- Move models folder to your cstrike folder inside the game folder
- if you're using a CT&T hands amxx addon, move the folder inside CT-hands folder to your cstrike folder first, then move models from T-Hands folder to alt folder inside cstrike models folder.
- Move the sound folder to you cstrike folder
